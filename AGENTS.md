# AGENTS.md — dotfiles

## Install

`./install.sh` symlinks `config/*` → `~/.config/` (skips `config/user/`, `config/generated/`), `home/*` → `~/`, `scripts/*` → `~/.local/bin/`.
`scripts/env` and `scripts/env.fish` are **copied** (not symlinked).
Before editing `~/.config/<app>/`, check `ls -la` — if it's a copy (not a symlink to the repo), editing the repo won't apply live.

**On this machine, nothing is currently symlinked** — 0 of 21 `~/.config/*`
dirs and 0 home dotfiles point here (repo 142 files vs live 1,330; 41 differ,
1,190 live-only; `~/.config/hypr` is 23 files here vs 202 live). So:

- Editing files in this repo does **not** change the running system.
- Running `./install.sh` **`rm -rf`s the live configs** and substitutes the
  repo versions (after backing up to `~/Backups/dotfiles-$(date)`) — 1,190
  live-only files get swapped out.
- `home/.zshrc:139` is the redacted `GEMINI_API_KEY` placeholder; live
  `~/.zshrc:139` has the real key. Symlinking replaces the real key with `""`.

Also note: most of `~/.config/hypr/scripts/` exists **only live** (35 scripts
there, 7 here).

## Git-ignored files that bite back

- `**/env.lua` — `config/hypr/modules/env.lua` exists on disk but is gitignored; changes won't be tracked.
- `config/hypr/hyprlock.conf` and `config/hypr/hyprlock-colors.conf` contain absolute paths and are gitignored.
- `config/matugen/generated/` and `config/rofi/generated/` are gitignored (matugen outputs).

## Hyprland (HyprMod Lua DSL)

- **Entry**: `config/hypr/hyprland.lua` requires 9 modules (in order): `monitors`, `binds`, `autostart`, `env`, `decorations`, `layout`, `misc`, `input`, `windowrules` + `hyprland-gui.lua`
- **API**: `hl.bind(key, handler)`, `hl.config({})`, `hl.env()`, `hl.on(event, fn)`, `hl.window_rule()`, `hl.layer_rule()`, `hl.dsp.*`, `hl.curve()`, `hl.animation()`, `hl.monitor()`, `hl.gesture()`, `hl.device()`
- **Reload**: `hyprctl reload` after editing any module
- **Binds format**: X11 keysym (`Escape` not `ESC`), `SUPER`, `SHIFT`, `CTRL`, `ALT`
- **Fullscreen**: `hl.dsp.window.fullscreen()` — toggles; accepts `{mode="fullscreen"|"maximized", action="toggle"|"set"|"unset"}`
- **env.lua dupes**: Lines 23–25 (`XDG_CURRENT_DESKTOP`, `XDG_SESSION_TYPE`, `XDG_SESSION_DESKTOP`) and 12–14 (`QT_QPA_PLATFORMTHEME`, `QT_QPA_PLATFORM`) are redeclared at lines 33–35 and 39–40. Later ones win.
- **`hyprland-gui.lua`**: Generated by HyprMod — overrides for blur, rounding, layout, gestures.

## Implicit window rule

`windowrules.lua:3-8` has a `suppress-maximize-events` rule matching all windows. Fullscreen (`Super+F`) is independent.

## Quickshell (external — NOT in repo)

Quickshell lives at `~/.config/quickshell/` and is NOT part of this repo. It runs 5 processes:

| Process | Entry | Purpose |
|---------|-------|---------|
| `pill` | `pill/shell.qml` | Main morphing hub (mixer, calendar, clipboard, power, media, settings, wallpaper picker) |
| `sidebar` | `sidebar/shell.qml` | Notification center + quick settings |
| `lock` | `lock/shell.qml` | PAM lock screen with cava visualizer |
| `launcher` | `launcher/shell.qml` | App launcher |
| `topbar` | `topbar/shell.qml` | Optional thin top bar |

- **IPC**: `qs -c <name> ipc call <name> <surface> "$(hyprctl activeworkspace -j | jq -r '.monitor')"`
- **Restart**: `pkill -f "qs -c <name>"` (watchdog respawns)
- **Colors**: Uses `~/.config/quickshell/*/Singletons/MatugenColors.qml` (generated by matugen)
- **Panel toggle**: `~/.config/hypr/scripts/toggle-panel.sh` (pill ↔ topbar, state in `~/.cache/quickshell-panel`)
